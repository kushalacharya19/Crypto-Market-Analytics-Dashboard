# Crypto Market Analytics Dashboard — 24H Analysis

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze cryptocurrency market data over the last 24 hours.

The dashboard uses cryptocurrency API data and Power Query transformations to provide dynamic market analysis for Bitcoin and Ethereum.

## 🎯 Objective

The main objective of this project is to build an interactive cryptocurrency analytics dashboard that allows users to:

- Monitor current cryptocurrency prices
- Analyze 24-hour price movement
- Compare Bitcoin and Ethereum
- Track 24-hour trading volume
- Identify 24-hour high and low prices
- Visualize price trends

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- CoinGecko API
- REST API
- Data Visualization
